
## Base de datos local en archivos JSON

Esta versión incluye un pequeño servidor local en Python para respaldar automáticamente los datos de la aplicación en archivos `.json` que puedes abrir con el Bloc de notas.

1. Instala Python 3 si no lo tienes.
2. Ejecuta `iniciar_campusconecta.bat`.
3. Abre `http://127.0.0.1:8000` en el navegador.
4. Usa la página normalmente; los datos se guardan en `base_de_datos/`.

Lee `README_BASE_DE_DATOS.txt` para más detalles. No abras `index.html` directamente con doble clic: para que guarde los datos en archivos, inicia primero el servidor local.
